## Commands for venv 
1. Create nvm Environment
```
Run the installer and follow the prompts to install nvm.
```
2. Restart system and check nvm version
```
$ nvm version
```
4. Install node Packages
```
$ nvm install node 23
```
5. Use Node package for project.
```
$ nvm use 23.6.0
```

## Project Specific 
1. Install React App gloablly
```
$ npm install -g create-react-app
```
1. Create a New React Project
```
$ npx create-react-app library-management-system
```
